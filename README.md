## Featured project: Pulse

An AI-assisted X-style web application built with Python, Flask, SQLite, HTML, CSS, and JavaScript.

Features include:
- Registration, login, and logout
- Posts, caption editing, likes, and replies
- User search, following, and profile bios
- Profile photos, image posts, and short MP4 videos
- Local timestamps and upload validation
